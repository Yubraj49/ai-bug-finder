# AI Bug Finder

AI Bug Finder is a simple web app that helps developers find and understand bugs in their code using AI.

Paste your code, submit it, and the app analyzes it and gives you useful feedback about possible errors and how they can be fixed.

## Features

* Find possible bugs in your code
* Get AI-powered explanations
* Simple and clean interface
* Frontend and backend setup
* Works with different types of code
* Easy to run locally

## Tech Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* OpenAI API

## How to Use

1. Open the website.
2. Paste your code into the input area.
3. Submit the code.
4. Wait for the AI to analyze it.
5. Check the bugs and suggestions returned by the app.

## Notes

This project is mainly made for learning and experimenting with AI-powered developer tools. The AI suggestions should still be checked before using them in a real project.
